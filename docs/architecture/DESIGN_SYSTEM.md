# DreamsAdverstings — Brand Identity & Design System

## 1. Visual Direction
- **Archetype**: Executive Ad-Tech & Cinematic Urban Media Marketplace
- **Color Palette**:
  - `Primary Dark (#101820)`: Hero backgrounds, navigation chrome, dark-mode portals, executive cards
  - `Gold Accent (#D9A441)`: Primary conversion CTAs, active filters, verified badges, map pin highlights
  - `White (#FFFFFF)`: Clean inventory cards, comparison tables, quotation sheets
  - `Background (#F4F5F6)`: Spacious marketplace canvas
  - `Primary Text (#1F2937)`: High-legibility headings and body text (WCAG AAA contrast on white)
  - `Secondary Text (#64748B)`: Metadata, dimensions, coordinates, and timestamps
