# Feature Gap Analysis & Upgrade Matrix

| Domain | Source A (Existing) | Target Production Requirement | Integration & Upgrade Action | Testing Required |
| :--- | :--- | :--- | :--- | :--- |
| **Owner & Staff RBAC** | 6 basic roles (`admin`, `sales_employee`, `finance_employee`, `inventory_manager`, `vendor`, `customer`) | **Single Master Owner** + **11 Staff Roles** (`owner`, `sales_manager`, `sales_executive`, `finance_manager`, `accounts_executive`, `inventory_manager`, `led_operations_manager`, `vendor_manager`, `campaign_manager`, `installation_staff`, `customer_support`) | Enforce `SINGLE_OWNER` invariant; restrict GST config to Owner; block finance/payment mutations for sales/inventory staff; add staff assignment & performance tracking. | Single-owner enforcement, 11-role permission boundaries, audit log capture. |
| **Inventory & LED Capacity** | 156 Pune assets; static overlap check | Static overlap + maintenance blocks + **LED capacity engine** (operating hours, slot duration, loop duration, plays/day, booked vs available slots) + Monthly/Weekly/Daily calendars | Add `LEDSlotCapacityEngine` and `MaintenanceBlock`; allow partial LED slot bookings without blocking remaining capacity. | Concurrent hoarding overlap, maintenance block, LED partial slot capacity. |
| **Indian GST Billing** | Flat 8% commission + 18% GST | Owner GST config, **HSN/SAC mapping**, CGST/SGST vs IGST (Place of Supply), cess, discounts, tax-inclusive/exclusive, **8 sequential atomic documents** | Build `IndianGSTBillingService` with atomic FY sequence generator, immutable issued invoices, and Credit/Debit Note correction workflows. | CGST/SGST vs IGST, HSN/SAC rates, atomic FY numbering, invoice immutability. |
| **Payments & Reconciliation** | Single full payment via Razorpay Test | Full & **partial payments**, outstanding balance, multiple payment records, failed payment guard, refunds, reconciliation | Upgrade `RazorpayPaymentService` to track installments, block receipts on failed payments, and compute reconciliation status. | Partial payments, failed payment receipt block, duplicate prevention, refunds. |
| **WhatsApp & Email** | Notification placeholders | **Meta WhatsApp Business Cloud API** + **AWS SES** with PDF attachments, `X-Hub-Signature-256` webhook, consent/opt-out, retry queue, delivery logs | Build `MessagingAutomationService` preserving invoices/payments even if delivery fails, with safe retry. | Opt-out enforcement, webhook signature, delivery failure resilience & retry. |
